RSC7 / texture dictionary / drawable format implementations
=========================================================

cRscWriter.cpp, cYtdWriter.cpp and cYdrWriter.cpp are original implementations
of the RSC7, texture dictionary and drawable binary formats. The formats were inspected in local
gen8/gen9 sample resources and cross-referenced with the following CodeWalker
files by dexyfex and contributors:
https://github.com/dexyfex/CodeWalker
  CodeWalker.Core/GameFiles/Resources/ResourceBuilder.cs
  CodeWalker.Core/GameFiles/Resources/ResourceFile.cs
  CodeWalker.Core/GameFiles/Resources/Texture.cs
  CodeWalker.Core/GameFiles/Resources/Drawable.cs

CodeWalker is NOT generally licensed under GPL-3.0. Its Readme_Src.txt states:
"This source code is released for educational purposes only."
No CodeWalker implementation is copied into the new writer. Binary field
layouts, format identifiers and runtime metadata are interoperability facts;
BC1/BC3 encoding, diffuse mipmap generation, single-page allocation and the
C++ API are local implementations. The application license is in LICENSE.
Sollumz/szio shader definitions and parameter defaults were also consulted:
https://github.com/Sollumz/szio
  src/szio/gta5/Shaders.xml
  src/szio/gta5/ShadersG9ParamsDefaults.json
  src/szio/gta5/ShadersG9TextureNameMapping.json
The normal_spec_decal binary binding layout was checked against the supplied
gen9 model, not inferred from defaults alone. Sollumz, szio and pymateria
are not runtime dependencies. No restricted CodeWalker implementation has
been ported. The MIT notice for szio is preserved below.
