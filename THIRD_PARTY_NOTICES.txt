RSC7 / texture dictionary format implementation
==============================================

cRscWriter.cpp and cYtdWriter.cpp are original implementations of the RSC7
and texture dictionary binary formats. The format was inspected in local
gen8/gen9 sample resources and cross-referenced with the following CodeWalker
files by dexyfex and contributors:
https://github.com/dexyfex/CodeWalker
  CodeWalker.Core/GameFiles/Resources/ResourceBuilder.cs
  CodeWalker.Core/GameFiles/Resources/ResourceFile.cs
  CodeWalker.Core/GameFiles/Resources/Texture.cs

CodeWalker is NOT generally licensed under GPL-3.0. Its Readme_Src.txt states:
"This source code is released for educational purposes only."
No CodeWalker implementation is copied into the new writer. Binary field
layouts, format identifiers and runtime metadata are interoperability facts;
BC1/BC3 encoding, diffuse mipmap generation, single-page allocation and the
C++ API are local implementations. The application license is in LICENSE.
Sollumz is a reference for the future GLB/material workflow, not a runtime
dependency, and no Sollumz code is included in this milestone.
